### Задание 1 **(2)**

*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*

**1.**
```cpp
int x = 10, y = 3;
std::cout << std::min(x = 15, x + y);
```

Вызовы аргументов `std::min` не задают порядок вычисления слева направо. В C++17 какой аргумент вычислится первым, не определено. Поэтому возможны разные результаты:

- если первым выполнится `x = 15`, второй аргумент станет `15 + 3 = 18`, результат — `15`;
- если первым вычислится `x + y`, он даст `13`, затем `x` станет `15`, результат — `13`.

**2.**
```cpp
int x = 10, y = 3;
x = 15, y += x, x += y;
```

Здесь запятые — оператор запятая, а не разделители аргументов. Он упорядочивает вычисления слева направо:

1. `x = 15` => `x = 15`;
2. `y += x` => `y = 3 + 15 = 18`;
3. `x += y` => `x = 15 + 18 = 33`.

Итог: `x == 33`, `y == 18`. Неоднозначности нет.

**3.**
```cpp
int x = 10, y = 9;
if (x > y++ && y++ > 9)
    std::cout << "yes" << endl;
std::cout << y;
```

Сначала сравнивается `10 > 9`: истина, после сравнения `y` увеличивается до `10`. Затем вычисляется правая часть `&&`: `10 > 9` — истина, после неё `y` становится `11`. Поэтому программа печатает:
```text
yes
11
```

Неоднозначности нет: `&&` вычисляется слева направо и не вычисляет правую часть только тогда, когда левая часть ложна.

### Задание 2 **(2)**

*Как записать исходные три инструкции одним выражением? Приведите несколько способов, в том числе с инкрементом.*

Исходный код:
```cpp
x = x + 1;
z = z + 2*x + 3*y;
y = y + 1;
```

Оператор запятая позволяет объединить выражения, сохранив их порядок:
```cpp
x += 1, z += 2 * x + 3 * y, y += 1;
```

C инкрементами:
```cpp
x++, z += 2 * x + 3 * y, y++;
```

Без запятых:
```cpp
z += 2 * ++x + 3 * y++;
```

Во всех трёх вариантах сначала увеличивается `x`, затем `z` пересчитывается с уже увеличенным `x` и прежним `y`, после чего увеличивается `y`.

### Задание 3 **(2)**

```cpp
std::vector<int> x(10);
for (int i = -1; i < 9;)
    x[++i] = 1;
```

`i` начинается с `-1`, поэтому первый `++i` даёт индекс `0`. Далее индексы последовательно принимают значения от `0` до `9`, и все десять элементов становятся равны `1`. Инициализировать `i` нулём в этом варианте нельзя: тогда первый индекс был бы `1`, а последний элемент оказался бы пропущен.

### Задание 4 **(2)**

Префиксный инкремент `++x` возвращает сам объект `x` как lvalue, поэтому результат можно использовать слева от присваивания. Суффиксный `x++` возвращает старое значение как временный результат, то есть rvalue, присваивать ему нельзя.

Сообщение об ошибке от компилятора:
```bash
zolars@Arsenys-MacBook-Air 04 % g++ 1.cpp -std=c++17
1.cpp:8:8: error: expression is not assignable
    8 |         (x++) = y;
      |         ~~~~~ ^
1 error generated.
```

### Задание 5 **(2)**

Да, это синтаксически корректное выражение, но значения оно **не перетасует**. В C++ запятая — оператор с низким приоритетом, а присваивание имеет более высокий приоритет, поэтому выражение разбирается как:

```cpp
a, (b = b), a;
```

Сначала вычисляется выражение `a` (просто `a`) и его результат отбрасывается, затем выполняется `b = b`, после чего снова вычисляется `a`. Ни одно присваивание не записывает значение `a` в `b` или наоборот.
